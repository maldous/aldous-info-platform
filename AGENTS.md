Use the scripts declared in package.json and the README's exact scope: npm run build, npm test, the separate architecture suite, and optional pinned Playwright browser checks. A DOM harness is not browser QA; source/export checks do not establish DNS, TLS or deployment. No npm or Python dependencies are needed for the ordinary build. Do not install tools or regenerate assets merely to orient yourself.

Make authorized changes on a task branch and preserve review history. Verify the intended full commit on the actual GitHub branch before remote build/test execution. Use an available, source-bound deterministic helper only when its deployed catalog includes this repository and target. Otherwise report that precise gap and use the repository's supported authorized executor, rather than inventing a helper binding. Treat run submission, terminal test result, review, publication and live verification as separate evidence.

Reconcile the existing site and publisher before any public effect. This repository deliberately omits original hosting identities, credentials and deployment bindings. Do not overwrite newer live changes from this export, create a replacement Site or change DNS, hosting, authentication or service state as a side effect of a source/documentation task. Preserve each asset's actual rights and existing notices. Source changes do not authorize release or data disclosure.
